# 冰雪奇緣北海道五日旅行手冊

2027 年 1 月 23 日至 27 日北海道冬季旅行的單頁行程網站。

## 網站

https://getwildysy.github.io/Hokkaido_travel/

## 功能

- 五日行程與旅行總覽
- 冬季服裝、禦寒與雪地安全建議
- 行李準備檢查清單與本機紀錄
- 手機與桌面瀏覽、列印

## 使用及部署

直接開啟 `index.html`，不需要安裝套件。GitHub Pages 請在 Settings → Pages 選擇 Deploy from a branch、main、/ (root)，並儲存。

## 資料說明

行程來源：[山富旅遊](https://www.travel4u.com.tw/group/product/SPK05270123A/#daily-tour)。活動日期、餐食、住宿及實際安排以旅行社及主辦方最終確認為準。本網站為個人旅行準備用途。
